# APPENDIX A

## SCREENSHOTS OF THE SYSTEM

This appendix presents screenshots of the IMPACT prototype, the web-based OJT monitoring portal developed in this study. Each figure corresponds to a page path exercised by the component test suite: the unit tests in `src/components/*.test.tsx` render one test file per module, and every module listed below is covered. The first twelve figures show the student portal session; the last three show the admin (OJT coordinator) panel session. Screenshots were captured from the running development build at a 1440 × 900 viewport.
